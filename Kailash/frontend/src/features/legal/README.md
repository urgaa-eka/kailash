# Feature: legal

The ~32 public legal / policy / compliance pages (Terms, Privacy, GDPR, DMCA,
SLA, Security, Accessibility, Transparency, …), all sharing `LegalPages.css`.
Public routes (not behind auth), registered in `@/App.js`. The globally-mounted
`LegalFooter` / `CookieConsent` are shared platform components, not part of this
feature.
